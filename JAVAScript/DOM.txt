Pasos para trabajar el dom desde javascript
*************************************
crear la etiqueta
var etiqueta = document.createElement("h2");
crear se le agrega contenido
var contenido = document.createTextNode("este es el contenido");
añadir el contenido a la etiqueta
etiqueta.appendChild(contenido);
agregar atributos a la etiqueta
etiqueta.setAttribute("align", "center");
agregar la etiqueta a HTML
document.getElementById("subtitulo").appendChild(etiqueta);

Nota: hay que crear un Div con el id "subtitulo"

 Ejercicio 12

Completar el código JavaScript proporcionado para que cuando se pinche sobre
 el enlace se muestre completo el contenido de texto. Además, el enlace debe
 dejar de mostrarse después de pulsarlo por primera vez. La acción de pinchar
 sobre un enlace forma parte de los "Eventos" de JavaScript que se ven en el
 siguiente capítulo. En este ejercicio, sólo se debe saber que al pinchar
 sobre el enlace, se ejecuta la función llamada muestra().

Ejercicio 13

Completar el código JavaScript proporcionado para que se añadan nuevos elementos
 a la lista cada vez que se pulsa sobre el botón. Utilizar las funciones DOM para
 crear nuevos nodos y añadirlos a la lista existente. Al igual que sucede en el
 ejercicio anterior, la acción de pinchar sobre un botón forma parte de los
"Eventos" de JavaScript que se ven en el siguiente capítulo. En este ejercicio,
 sólo se debe saber que al pinchar sobre el botón, se ejecuta la función
 llamada anade().

<script type="text/javascript">
function anade() {
  var elemento = document.createElement("li");
  var texto = document.createTextNode("Elemento de prueba");
  elemento.appendChild(texto);

  var lista = document.getElementById("lista");
  lista.appendChild(elemento);

  var nuevoElemento = "<li>Texto de prueba</li>";
  lista.innerHTML = lista.innerHTML + nuevoElemento;
}
</script>
